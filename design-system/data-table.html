Usage Notes

Responsive Tables

Always wrap tables in a container with overflow-x-auto for horizontal scrolling on small screens.

Hover States

Use hover:bg-muted/50 on rows for better interactivity.

Alignment

Use text-left for text, text-right for numbers/actions.

Accessibility

Use semantic <thead>, <tbody>, and <th> elements.
