Slider

An input where the user selects a value from within a given range.

Basic Slider

<div class="slider">
  <input type="range" min="0" max="100" value="50" class="w-full" />
</div>

Usage Notes

Mobile Touch Optimization

The slider is optimized for mobile touch:

  • touch-action: none - Prevents scrolling while dragging
  • 20px thumb - Large enough for easy touch (Apple recommends 44px minimum touch target)
  • Works with touch events (touchstart, touchmove, touchend)

Attributes

  • min - Minimum value
  • max - Maximum value
  • step - Increment value (default: 1)
  • value - Initial value

Events

Use oninput for real-time updates or onchange for updates after releasing.

Accessibility

The slider can be controlled with keyboard (arrow keys) and supports screen readers. Always include a label.
