CSS Animation

/* Skeleton pulse animation */
@keyframes skeleton-pulse {
  0%, 100% {
    opacity: 1;
  }
  50% {
    opacity: 0.5;
  }
}

.skeleton {
  animation: skeleton-pulse 2s cubic-bezier(0.4, 0, 0.6, 1) infinite;
}

/* Usage: Add both 'skeleton' and 'bg-zinc-200 dark:bg-zinc-800' classes */

Usage Notes

Basic Class

Add the skeleton bg-zinc-200 dark:bg-zinc-800 classes to any element to apply the loading animation and background color.

Sizes

Use Tailwind utility classes for sizing:

  • h-4 - Small line (16px)
  • h-8 - Medium line (32px)
  • h-12 - Large element (48px)
  • w-full - Full width
  • w-1/2 - Half width

Shapes

Control the shape with border radius:

  • rounded - Small radius (4px)
  • rounded-md - Medium radius (6px)
  • rounded-lg - Large radius (8px)
  • rounded-full - Circle/Pill

Example Usage
