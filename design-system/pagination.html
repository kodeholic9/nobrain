Pagination

Navigation for paginated content with page numbers and controls.

Basic Pagination

1 2 3 4 5 
<nav class="flex items-center gap-1">
  <!-- Previous Button -->
  <a href="#" class="inline-flex items-center justify-center ... h-9 w-9 border">
    <svg>...chevron left...</svg>
  </a>
  
  <!-- Page Numbers -->
  <a href="#" class="inline-flex items-center justify-center ... h-9 w-9">1</a>
  <a href="#" class="inline-flex items-center justify-center ... h-9 w-9 bg-primary text-primary-foreground">2</a>
  <a href="#" class="inline-flex items-center justify-center ... h-9 w-9">3</a>
  
  <!-- Next Button -->
  <a href="#" class="inline-flex items-center justify-center ... h-9 w-9 border">
    <svg>...chevron right...</svg>
  </a>
</nav>

Usage Notes

Active State

Use bg-primary text-primary-foreground for the current page.

Disabled State

Add disabled attribute and use disabled:opacity-50 for unavailable controls.

Responsive Text

Use hidden sm:inline to hide labels on mobile.

Accessibility

Use <nav> element and consider adding aria-label="Pagination".
