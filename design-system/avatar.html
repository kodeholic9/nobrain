Avatar

An image element with a fallback for representing the user.

Default

  <img class="aspect-square h-full w-full" src="..." alt="Avatar" />
</span>

Shows initials when image fails to load or is not provided.

Usage Notes

Structure

The Avatar uses a span element with relative positioning to allow for absolute positioned indicators.

Image Handling

Always provide an alt attribute for images. Use fallback initials when images fail to load.

Accessibility

Consider adding aria-label or title attributes for better screen reader support.
